<p>What was the root cause?</p>
<p>The problem was not the detached Oracle Home.</p>
<p>The issue was that the CSS initialization resource was not started on node2, so the remainder of the Clusterware stack never came online.</p>
<p>Since CSS was down:</p>
<p>srvctl could not communicate with CRS.<br />ASM remained idle.<br />CRSD never started.<br />The node appeared as Inactive from node1.</p>
<p>By starting ora.cssd -init, you triggered the entire Clusterware startup.</p>
<p>crsctl start resource ora.cssd -init</p>
